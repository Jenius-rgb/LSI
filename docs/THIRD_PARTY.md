## Local AI-assistant tooling (not part of the repository)

Everything Claude Code (ECC), a collection of Claude Code skills, agents, commands and hooks.

- Project: Everything Claude Code (ECC), by Affaan Mustafa.
- Version: 2.2.3 (from the upstream `plugin.json`).
- Source: https://github.com/affaan-m/ECC
- Licence: MIT, Copyright (c) 2026 Affaan Mustafa. Checked against the upstream `LICENSE` file; a
  copy is kept at `.claude/ECC-LICENSE.txt`.
- Where it lives: `.claude/skills/` and `.claude/agents/`. The `.claude/` folder is git-ignored
  (`.gitignore`), so none of this is committed, shipped or used by the design flow.
- Skills extracted (13): tdd-workflow, verification-loop, search-first, python-testing,
  python-patterns, pytorch-patterns, change-impact, safety-guard, ai-regression-testing,
  context-budget, strategic-compact, mle-workflow, benchmark-methodology.
- Agents extracted (6): planner, code-reviewer, python-reviewer, silent-failure-hunter,
  code-explorer, tdd-guide.
- Not extracted: the ECC plugin itself, all hooks, all commands and every other skill or agent.
- Local modifications: none. Each copied file is byte-identical to the upstream file (SHA-256
  compared on 2026-11-23). The upstream `metadata.origin: ECC` front matter is kept.
- Known notes: `tdd-workflow` mentions an ECC helper script (`setup-package-manager.js`) that is not
  installed here and is not needed for Python or Verilog work; `strategic-compact` mentions an ECC
  hook that is deliberately not installed, so that skill is advisory only.
