# Third-party software and data

No third-party source code is copied into this repository. Licence names below were written
from general knowledge; confirm them against the packages before submission.

| Item | Use | Licence (to confirm) |
| --- | --- | --- |
| NumPy, PyTorch, torchvision | model training and golden model support | BSD |
| PyYAML | configuration | MIT |
| pytest | test runner | MIT |
| Hypothesis | property tests | MPL 2.0 |
| Matplotlib | plots | Matplotlib licence |
| OpenCV | camera and preprocessing | Apache 2.0 |
| Flask | dashboard | BSD |
| Icarus Verilog | simulation | GPL |
| Verilator | lint | LGPL / Artistic |
| Vivado (AMD) | synthesis, xsim | commercial, per its licence |
| CIFAR-10 dataset | temporary training data (downloaded to `data/`, not committed) | see its website |
| AMD Clocking Wizard v6.0 IP (`clk_wiz`) | MMCM2 with AXI4-Lite reconfiguration, generated by Vivado from Tcl at build time (ADR-023); no generated IP source is committed | AMD IP, licensed with Vivado |
| AMD data sheets and user guides (DS189, DS180, UG480, PG065) | facts with page numbers; kept locally, not committed (`docs/vendor/README.md`) | AMD legal notice in each document |
| gpiozero, spidev, picamera2 (Raspberry Pi) | GPIO, SPI and camera on the Pi | BSD-3-Clause, MIT, BSD-2-Clause (to confirm) |

Bibliographic references for design ideas are in `docs/PRIOR_ART.md`.
